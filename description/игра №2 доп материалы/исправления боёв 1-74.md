# Исправления боёв 1–74

> **Уточнение после самопроверки:** устранение точных совпадений не обеспечило уникальность. Новые серии 265 противников используют девять общих рецептов; подробная проверка каждого уровня — в [самопроверке уникальности](самопроверка%20уникальности%201-74.md). Перечисленные ниже проверки механики не являются проверками уникальности.

Авторские решения: образ, приём, ошибка привычки, честный ответ. Оценка интереса требует игры с людьми; ниже — проверяемый замысел.

## Что изменено

- 53 уровня, 265 противников: заменены три обычные серии на основной приём и два развития. Короткие исходные мотивы сохранены. Поздние варианты открываются по HP-фазам; один и тот же старт может закончиться иначе.
- В уровнях 29 и 31 удалены девять дубликатов серий, обходивших память последних двух комбинаций.
- Для всех боёв движок резервирует всю серию до запуска, учитывает ещё не появившиеся атаки и ждёт освобождения поля. Цепь не накладывается на другую цепь или баррикаду. Во время обязательной очереди допускается только короткая дополнительная серия при малой заполненности поля.
- Между сериями сохраняется время реакции от последнего появления предыдущей. Для новых завершений добавлена небольшая пауза. Пульсирующие серии имеют отдельный промежуток между двумя группами.
- Базовый темп изменённых боёв с длинными однообразными паузами скорректирован в пределах 15% исходного значения. HP, характеристики героев, коэффициенты урона и телеграфы не повышались/не сокращались.
- Таблица admin-boss-pattern-panel.html показывает исполняемые названия приёмов и их доступность по фазам. Версия загрузки level.html обновлена, чтобы браузер получил новые данные.

Он не используется как доказательство сохранности их исходных атак: миграция дописывает новые способности, сохраняя существующие записи. Их урон дополнительно сравнивается с сохранённым текущим пулом каждого босса.

## Поля сценария для дальнейшей настройки

У комбинации: `openingOrder` — порядок знакомства; `signature` — фирменный приём; `minPhase`/`maxPhase` — доступность по HP-фазе; `shotDelayMs` — минимальный шаг появления; `shotGapsMs` — минимальные промежутки между соседними атаками; `recoveryMs` — пауза после последнего появления. Эти значения могут удлинить защитный интервал, но не отменить его. У профиля: `combatIdentity`, `combatTrick`, `signatureEvery`. Возвращение сигнатуры ограничено доступностью фазы и поля; безопасность приоритетнее частоты.
