КОНСТРУКТОР БОЁВ УРОВНЯ (построение, не проверка). Создан 2026-09-19 при переработке уровней 1-10.
Проверка готовности уровня — ТОЛЬКО scripts/combat-data-inventory.js --check=N (правила, часть А).
Запуск: node scripts/level-builder/run.js N   (читает designN.js, собирает боевые данные, пишет lvlData/gameDataN.js,
затем сам вызывает --check=N и печатает вывод). designN.js — авторский дизайн: профиль, скаляры, семейства приёмов
по боссам (fam.js), подписи. compose.js подбирает скорости/высоты под задуманный порядок и ритм и отсеивает
кандидатов, совпадающих по «решению игрока» с другими уровнями. diagreal.js — диагностика на реальном движке
(устойчивость порядка прилёта при speedVariance и стиле движения); не заменяет --check.
