# Музыка игры

## Музыка хаба

За сопровождение `index.html` отвечает `hub-music.js`, используется композиция `elerya-calm.mp3`.

- Трек пытается запуститься при открытии хаба; если браузер запрещает автозапуск, начинает звучать после первого действия пользователя.
- Открытие выбора персонажей, прокачки и других окон не перезапускает музыку.
- При скрытии вкладки музыка плавно приостанавливается, при возвращении продолжает звучать.
- При переходе на доступный уровень трек затихает за 0,9 секунды.
- Позиция сохраняется в `sessionStorage`, поэтому после возвращения из боя композиция продолжается примерно с прежнего места, а не начинает вступление заново.

Громкость хаба задаётся полем `volume` в начале `hub-music.js`.

## Боевая музыка

Плейлист находится в `playlist.js`, логика воспроизведения — в `battle-music.js`.

## Как работает выбор

- Музыка начинается только после нажатия «Вперёд».
- Движок определяет настроение следующего трека по уровню, порядку босса, типу движения, темпу атак, длине комбинаций, скорости снарядов и доле неожиданных серий.
- Профиль нового босса влияет только на следующую композицию. Уже звучащий трек не обрывается при появлении босса, смене фазы или выборе временного улучшения.
- Последние две композиции исключаются из выбора, пока в плейлисте достаточно других вариантов.
- Между композициями во время боя остаётся естественная пауза 1,2–2,8 секунды.
- На экране победы или поражения текущая композиция доигрывает. После её окончания новая уже не запускается.
- `Dvorak Polka` намеренно имеет пониженный вес: хаотичное «казино»-настроение остаётся редким событием.

Автоматически поддерживаются настроения `folk`, `adventure`, `heavy`, `cunning`, `heroic` и `chaos`.

## Как добавить композицию

1. Положить сжатый MP3 или OGG в эту папку. Лучше использовать имя файла без пробелов.
2. Добавить объект в массив `tracks` файла `playlist.js`:

```js
{
    id: 'unique-track-id',
    src: 'music/track-name.mp3',
    title: 'Название',
    author: 'Автор',
    moods: ['adventure', 'heroic'],
    weight: 1,
    volume: 0.4
}
```

- `moods` — подходящие роли композиции.
- `weight` — относительная частота выбора среди подходящих треков.
- `volume` — громкость относительно общей громкости плейлиста.
- `enabled: false` временно исключает композицию.

## Ручное исключение для уровня или босса

Обычно файлы уровней редактировать не нужно. Если конкретному боссу требуется авторское настроение, в его профиль внутри `bossCombatConfig.bosses` можно добавить:

```js
enem5: {
    movementStyle: 'lateRush',
    // остальные боевые параметры...
    musicMood: ['heroic', 'heavy']
}
```

Первое настроение имеет больший приоритет. Для редкой постановочной сцены можно закрепить одну композицию через `musicTrack: 'fantasy-armies'`, но обычным боссам это не рекомендуется: фиксированные треки быстрее приедаются.

## Размер и лицензии

Текущий набор из шести композиций занимает около 22,4 МБ. Общий размер игровой сборки проверяется командой:

```text
node scripts/runtime-size-report.js
```

Скрипт завершится с ошибкой при превышении лимита 100 МБ. Перед добавлением музыки нужно обновить `LICENSES.md`, сохранить ссылку на источник и SHA-256 файла.
